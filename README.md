# University Management System | January 2026 - April 2026

This project, developed in TypeScript, features a university management system for classes, allowing universities to manage courses and sections.

Technical achivements: 
- User-friendly dashboard written in HTML, CSS and JS, enabling the end user to examine courses and perform CRUD operations on courses, organizations and sections.
- RESTful API in TypeScript to handle data validation, routing, and persistent storage.
